# 三角函數連線（trig-chain）設計文件

- 模板：T7 盤面連線消除
- 單元：高中一年級　三角函數的特殊角值與象限符號
- 學習表現：待查
- 定位：發展活動與形成性評量；適用於特殊角值教學後的 5～10 分鐘練習
- 技術等級：Level 3（沿用 T7 單人練習、老師開房、即時看板與事件留痕）

## 1. 教學目標

學生將能：
1. 組出 `sin`、`cos`、`tan` 在特殊角的正確函數等式。
2. 依角所在象限判斷函數值的正負，並處理 `tan 90°` 不存在的特例。
3. 辨識並修正正餘弦混淆、特殊角值記錯與象限符號錯誤。

## 2. 評量證據與記錄欄位

- 學生依序串起「函數 → 角度 → 等號 → 函數值」，形成正確等式。
  - `chain_ok`：`{v, content, tiles, len, gain, points, combo, score, summary, ms}`
- 學生提交不成立的等式時，能依回饋修正關係。
  - `chain_fail`：`{v, content, tiles, len, kind, counted, score, ms}`
  - `kind` 使用 `sin_cos_swap`、`special_value_mixup`、`quadrant_sign`、`tan_undefined`、`invalid_relation`、`short`。
- 學生需要提示的程度與自願重玩情形。
  - `hint`：`{v, content, level}`；`game_end`：分數、完成數、錯誤數、提示數與時間。

## 3. 核心機制

- 遊戲動詞：建構並驗證三角函數等式。
- 基本操作：在相鄰方塊中串出例如 `sin → 30° → = → 1/2`；正確才消除，錯誤則指出關係哪裡不成立。
- 主題與機制：方塊是函數、角度、等號與精確函數值；消除規則就是三角函數關係，不是外加獎勵。
- 兩問檢驗：
  1. 拿掉數學就不能判斷哪些鏈可消除，遊戲無法進行，通過。
  2. 遊戲動詞是組出並驗證等式，與達標證據相同，通過；本活動聚焦特殊角值與符號的建構及熟練，不宣稱涵蓋圖形或公式推導。

## 4. 誤解、規則與誘答

| 誤解代碼 | 誘答或規則 | 診斷回饋方向 |
|---|---|---|
| `sin_cos_swap` | 例如 `sin 30° = √3/2`、`cos 30° = 1/2` | 對照同一特殊角的正弦與餘弦值，指出函數名稱混淆 |
| `special_value_mixup` | 例如 `sin 45° = √3/2`、`tan 60° = √3/3` | 顯示該函數與角度的正確特殊角值 |
| `quadrant_sign` | 例如 `sin 210° = 1/2`、`cos 120° = √3/2` | 先判斷象限正負，再確認參考角大小 |
| `tan_undefined` | `tan 90° = 0` 或任何有限值 | `cos 90° = 0`，所以 `tan 90° = sin 90° / cos 90°` 不存在 |
| `invalid_relation` | 函數、角度、等號與值的順序錯亂 | 提示固定結構為「函數 → 角度 → = → 函數值」 |
| `short` | 少於 4 格 | 視為可能手滑，不扣分、不計入誤解 |

## 5. 回饋與計分

- 每條 4 格正確等式基礎 2 分；連擊倍率沿用 T7，為 `1 + 連擊數 × 0.5`，以整數計分。
- 錯誤扣 1 分，總分不低於 0，連擊歸零；短鏈不扣分。
- 第 3 層提示會示範完整關係，示範後那一次成功不給連擊倍率。
- 不回加無關金幣或抽獎；分數只來自正確建構三角函數關係。

## 6. 鷹架與分層

- 工作區同時呈現等式預覽、盤面與目前串接內容。
- 三層提示：策略提醒 → 指出可起點 → 示範完整等式。
- 函數值採精確根號與分數表示；不使用小數近似。
- 先以常見特殊角建立熟練，再由含負值與 `tan` 的題目辨別象限與定義。

## 7. 課堂運作

- 單人 3 分鐘自主練習，或老師開房設定 3～10 分鐘；學生各自盤面作答。
- 課堂流程：加入與規則說明 2 分鐘 → 連線練習 5～10 分鐘 → 依看板誤解分布講評 3 分鐘。
- 房間由 `endsAt` 控制時間，任一端都能推進結束；老師可提前結束。
- iPad 預設點選模式，觸控目標至少 48px，亦提供拖曳模式。

## 8. 資料留痕與後續使用

- 老師看板彙整完成數、錯誤數、連擊與誤解代碼分布，可匯出 CSV。
- 下節課依 `sin_cos_swap`、`special_value_mixup`、`quadrant_sign`、`tan_undefined` 的高頻類型安排複習。
- 僅使用班級－座號或暱稱，不收集真實姓名；作答資料只用於課堂形成性評量。

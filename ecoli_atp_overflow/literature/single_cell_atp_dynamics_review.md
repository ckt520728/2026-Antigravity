# 大腸桿菌單細胞 ATP 動態監測技術與能量異質性綜述
## Single-cell ATP Dynamics in *Escherichia coli*: Biosensing Technologies, Microfluidics, and Bioenergetic Heterogeneity

---

## 摘要 (Executive Summary)

腺苷三磷酸 (Adenosine Triphosphate, ATP) 是所有活細胞內部驅動生物合成、物質轉運與生理維持反應的通用自由能貨幣。長久以來，微生物生理學研究多依賴龐大細胞群體（Bulk Population）之裂解萃取測定（如螢光素酶-螢光素發光法），此類宏觀量測無可避免地遮蔽了單個細胞間在代謝通量、能量狀態以及生長動力學上的顯著表型異質性（Phenotypic Heterogeneity）。

近年來，隨著**基因編碼螢光生物感測器**（Genetically Encoded Fluorescent Biosensors，如 ATeam、QUEEN 系列及 PercevalHR）與**微流體母細胞晶片**（Mother Machine）技術的突破性結合，科學界首次實現了對大腸桿菌 (*Escherichia coli*) 單細胞在數十至數百個連續世代中，以高時空解析度即時監控絕對 ATP 濃度及 ATP:ADP 比值的動態漲落。

本綜述系統性評估當前主流單細胞 ATP 生物感測器之生物物理與生化參數，剖析 Mother Machine 微流體平台在長週期細胞追蹤與光毒性控制中的關鍵技術，並深入探討大腸桿菌在生理穩態與飢餓/逆境脅迫下的能量異質性機制、噪聲起源，以及生長速率（Growth rate）與維持能量（Maintenance energy, Pirt 模型）在單細胞尺度的動態偶聯與去偶聯現象。

## 一、基因編碼 ATP 螢光感測器之生物物理與生化評估

為在單細胞活體中無損、即時地監測能量代謝，蛋白質工程學家發展出兩種主要策略：(1) **基於 Förster 共振能量轉移 (FRET) 的比例計量感測器**；(2) **基於單一環狀排列螢光蛋白 (cpFP) 結構重排的激發比率型 (Excitation-ratiometric) 感測器**。

### 1.2 生物物理機制深度解析

#### 1.2.1 QUEEN 系列：無 FRET 單一螢光蛋白的異構體轉換
QUEEN (Quantitative Understanding of Energy levels via a fluorescent Indicator) 透過基因工程將枯草芽孢桿菌 (*B. subtilis*) $F_oF_1$-ATP 合成酶的 $\epsilon$ 次單元嵌入至黃綠色螢光蛋白的環狀排列異構體 (cpEGFP) 中。
- **分子機制**：當 ATP 分子嵌入 $\epsilon$ 次單元的兩個 C 端 $\alpha$-螺旋與 N 端 $\beta$-夾心結構域所構成的結合口袋時，引發 $\epsilon$ 結構域的劇烈構型閉合。該應力傳導至 cpEGFP 發色團周圍的 $\beta$-桶狀結構，使發色團周圍的質子化/去質子化平衡產生位移。
- **光譜特性**：未結合 ATP 時，發色團呈中性質子化狀態，主激發峰位於 400 nm；結合 ATP 後，去質子化陰離子狀態佔優勢，主激發峰紅移至 494 nm。測量 400 nm 與 494 nm 激發下的發射光比值 ($R_{400/494}$)，可完全消除因感測器表現量、細胞體積差異與聚焦深度所引起的強度偽影。
- **抗 pH 干擾的物理基礎**：Yaginuma 等人精心篩選的 cpEGFP 支架具有較高的發色團屏障，使其去質子化化學平衡在 pH 7.3 至 8.8 之間維持高度恆定，有效克服了早期螢光生物感測器容易受胞內質子濃度波動干擾的致命缺陷。

#### 1.2.2 ATeam 系列：FRET 距離與偶極角之剛性重組
ATeam 依賴於供體（mseCFP）與受體（cp173Venus）之間的 Förster 能量轉移。未結合 ATP 時，PS3 嗜熱菌 $\epsilon$ 次單元處於延展的彈性狀態，兩端螢光團距離較遠 ($>6\text{ nm}$)，FRET 效率極低；結合 ATP 後，$\epsilon$ 次單元折疊為緊湊的髮夾狀結構，拉近兩端螢光團距離至 Förster 臨界半徑 ($R_0 \approx 4.9\text{ nm}$) 以內，激發 CFP 時能量共振轉移至 Venus，產生顯著的黃光發射。
- 其生物物理局限在於 **Venus 螢光團的酸性敏感性**。大腸桿菌在遭遇代謝抑制、有機酸積累或膜電位崩塌時，胞內 pH 常自中性 (7.5-7.6) 驟降至 6.0-6.5，導致 Venus 螢光強度大幅衰減，進而導致 ATeam 的 FRET 比率被誤判為 ATP 急劇耗竭。

#### 1.2.3 PercevalHR：熱力學能量荷 vs 絕對儲備之辯證
- **絕對莫耳濃度 ([ATP]) 的生物學意涵**：反映細胞內部高能磷酸鍵的**總容量池**。對於細菌中具有高米氏常數 ($K_m$) 的代謝酵素（如糖解激酶、氨甲醯磷酸合成酶），絕對 [ATP] 決定了催化反應的底物飽和度。
- **能量比值 ([ATP]/[ADP]) 的生物學意涵**：反映 ATP 水解反應的**即時熱力學自由能變化**：
  $$\Delta G_{ATP} = \Delta G^\circ + RT \ln \left( \frac{[\text{ADP}][\text{P}_i]}{[\text{ATP}]} \right)$$
  細胞的生命活動（尤其是 ABC 轉運蛋白、質子泵與分子伴侶折疊）本質上是由負值極大的 $\Delta G_{ATP}$ 所驅動，而非單純由 [ATP] 分子數所驅動。PercevalHR 捕獲了 GlnK1 對 ADP 與 ATP 相互競爭的生物物理特性，提供了比值層級的能量荷讀數；然而，在細菌遭遇劇烈應激引發胞內酸化時，PercevalHR 必須藉由同時激發紅光 pHRed 感測器建立多變量校準曲線，大幅提升了光學顯微硬體與影像處理演算法的複雜度。

## 二、微流體 Mother Machine 晶片在單細胞長期動態追蹤中的技術優勢與光毒性控制

### 2.1 晶片幾何設計與微流體動力學優勢

Wang 等人 (2010, Jun Lab) 發明的 **Mother Machine** 是當代定量微生物生理學的基石平台。

```
                    新鮮營養液連續流動 (Main Trench, 寬 ~100 μm, 高 ~20 μm)
  ===================================================================================> 流速 ~1-2 mL/h
      | |       | |       | |       | |       | |       | |       | |       | |
      | |       | |       | |       | |       | |       | |       | |       | |
      | |       | |       | |       | |       | |       | |       | |       | |   微死端通道 (Dead-end Trenches)
      | |       | |       | |       | |       | |       | |       | |       | |   寬: 1.2-1.3 μm, 高: 1.2 μm, 長: 25-30 μm
      |*|       |*|       |*|       |*|       |*|       |*|       |*|       |*|   [*] 母細胞 (始終定居於通道盲端)
  -----------------------------------------------------------------------------------
```

1. **嚴格的化學微環境均勻性**：
   - 主通道內持續以微升/小時級別層流泵入新鮮培養基，通道盲端與主通道之間的物質交換純粹依賴**微米尺度的分子擴散**（擴散時間常數 $\tau \sim L^2 / 2D \approx (25\ \mu\text{m})^2 / (2 \times 500\ \mu\text{m}^2/\text{s}) \approx 0.6\text{ 秒}$）。
   - 徹底消除了傳統瓊脂糖襯墊 (Agarose pad) 培養中局部微環境葡萄糖耗竭、乙酸鹽/乳酸等副產物堆積以及局部菌落密度效應引起的干擾。
2. **單一譜系的代際連續追蹤**：
   - 桿狀的大腸桿菌在直徑約 1.2-1.3 $\mu$m 的死端微通道中呈嚴格的**單線性排列**生長。
   - 位於最底部的母細胞（舊極點細胞，Old-pole cell）始終滯留在盲端，每次分裂產生的子細胞將先前的細胞逐步向開口端推擠，最終溢出開口被主流體沖走。研究人員得以持續監測同一母細胞及其直接後代超過 **100 至 200 個連續分裂週期**，實現跨代衰老與隨機遺傳學的高保真度統計。

### 2.2 單細胞時序成像之光毒性 (Phototoxicity) 物理機制與實驗控制策略

在使用活細胞螢光感測器（特別是需要 400-435 nm 藍紫光激發的 QUEEN-2m 與 ATeam）進行長達數十小時的連續觀測時，**光毒性**是導致細胞生長遲緩、能量代謝失常甚至細胞死亡的最主要人工偽影來源。

#### 2.2.1 光毒性的生物物理來源
- **活性氧物質 (ROS) 的光敏生成**：發色團在激發態三重態 ($T_1$) 容易與周圍的溶解氧分子進行能量轉移，產生極具細胞毒性的**單線態氧 ($^1O_2$)** 及超氧陰離子 ($O_2^{\bullet-}$)。
- **DNA 損傷與 SOS 反應**：ROS 氧化破壞鳥嘌呤核苷酸（形成 8-oxo-dG），引發 DNA 雙鏈斷裂並活化 RecA-LexA 依賴之 SOS 應激反應，導致細胞停止分裂、發生異常絲狀化（Filamentation）。
- **粒線體/呼吸鏈去偶聯與 ATP 人工崩跌**：光化學氧化作用破壞細菌細胞膜上的細胞色素氧化酶與電子傳遞鏈複合物，耗散質子驅動力 (Proton Motive Force, PMF)，直接誘發感測器偵測到人為的 ATP 濃度暴跌。

#### 2.2.2 實驗緩解策略矩陣

```
[光化學劑量管理]  ────> 激發強度降至最低 (<1-2 W/cm²) + 曝光時間縮短 (<30-50 ms)
[光譜優化]        ────> 採用窄頻帶 LED 光源；避開紫外光波段；選用長波長/低光毒性螢光蛋白
[取樣時序優化]    ────> 穩態生長採 5-10 min/frame 間隔；動態擾動切換為自適應脈衝觸發
[探測靈敏度]      ────> 背照式 sCMOS 相機 (QE > 85-95%)，降低激發光子通量需求
[抗氧化防護]      ────> 微流體培養基中添加抗壞血酸、Trolox 或低濃度過氧化氫酶 (Catalase)
```

1. **激發劑量極小化**：將藍紫光激發功率密度控制在 $<1.5\text{ W/cm}^2$，單次曝光時間限制在 $30 - 60\text{ ms}$ 之內。
2. **取樣間隔權衡 (Temporal Sampling Trade-off)**：在生長穩態期間，將成像頻率設定為每代 3-5 次（即每 5-10 分鐘一次），避免頻繁激發；僅在添加碳源或抗生素等動態躍變窗口期短暫提高取樣頻率至 1-2 分鐘一次。
3. **高量子產率探測硬體**：配備高量子效率（QE > 90%）的背照式 sCMOS 相機，並採用無暗電流雜訊的電子快門與自動硬體對焦系統 (Hardware Autofocus)，確保在最小激發光強下獲得足夠的信噪比 (SNR > 10)。

## 三、單細胞能量異質性機制與動力學分析

### 3.1 生理穩態下的 ATP 分佈與變異係數 (CV)

利用 QUEEN-2m 與 Mother Machine 對野生型大腸桿菌（如 MG1655、BW25113）在指數生長期的單細胞測定顯示：

1. **生理穩態濃度**：
   - 葡萄糖最小合成培養基 (M9-Glucose, 37°C)：單細胞細胞質絕對 [ATP] 均值穩定在 **$1.5 - 2.5\text{ mM}$** 之間。
   - 富營養複合培養基 (LB 或補加豐富胺基酸)：單細胞 [ATP] 均值顯著提升至 **$3.5 - 5.0\text{ mM}$**。
2. **細胞間異質性與變異係數 (Coefficient of Variation, $CV = \sigma / \mu$)**：
   - 在均勻恆定的生長環境下，大腸桿菌群體的單細胞 [ATP] 呈現高度對稱的**單峰近似高斯分佈**。
   - 其變異係數 $CV$ 嚴格約束在 **$15\% - 25\%$** 之間。此一數值顯著低於傳統螢光蛋白（如 GFP，受轉錄/轉譯噪聲影響其表現量 $CV$ 常達 30%-50% 以上），表明細菌內部存在強大且嚴密的代謝負反饋調節迴路，主動維持腺苷酸庫存的能量恆定性 (Robust Homeostasis)。

---

### 3.2 飢餓與逆境脅迫下的時序脈衝與雙峰分佈 (Bimodal Distribution)

當外部環境發生劇烈變動（如突然撤除碳源或施加呼吸鏈抑制劑）時，穩態的分佈特徵被徹底打破：

```
穩態 (對數生長期)           急性飢餓 (碳源撤除 1-2 小時)        深度持留態 (Persister 亞群)
     相對細胞數                       相對細胞數                       相對細胞數
         |   ***                          |  **                           |  ***** (低能量休眠)
         |  *   *                         | *  *   **                     |  *   *
         | *     *                        |*    * *  *                    |  *    *    * (少數高能量)
         |*       *                       *      *    *                   *       *  *
         +---------                   ---+-------------                   +----------------
          0 1 2 3 4 [ATP] (mM)            0 1 2 3 4 [ATP] (mM)            0 1 2 3 4 [ATP] (mM)
           (CV ~ 18%, 單峰)                (CV ~ 45%, 變異擴大)            (雙峰分佈, 能量崩塌亞群)
```

1. **能量崩塌與雙峰分佈**：
   - 在葡萄糖耗竭初期，平均 [ATP] 快速自 2.0 mM 衰減至 0.5-0.8 mM。
   - 群體變異係數 $CV$ 飆升至 **$40\% - 65\%$**，細胞群體分化為兩個鮮明的亞群：
     - **亞群 A (低能量崩潰細胞, ~80-90%)**：[ATP] 驟降至 $<0.5\text{ mM}$，代謝活性極低。
     - **亞群 B (高能量殘存細胞, ~10-20%)**：藉由內部貯藏物質（如糖原、多磷酸鹽）分解或轉移性途徑，維持 [ATP] 在 1.0-1.5 mM 達數小時。
2. **隨機時序脈衝 (Stochastic Pulses)**：
   - 在單細胞時序軌跡中，部分處於飢餓過渡期的細胞展現出週期性的 ATP「脈衝跳躍」。該現象源於微量代謝中間產物在細胞內酵素網絡中積聚後觸發的隨機爆發性催化（Burst-like catalytic events），突顯了非穩態下單細胞酵素通量的隨機動力學本質。

---

### 3.3 生長速率與維持能量在單細胞層級的偶聯與去偶聯

#### 3.3.1 巨觀 Pirt 方程之熱力學回顧
S. J. Pirt (1965) 提出之經典維持能量模型，描述了微生物群體基質消耗速率 ($q_s$) 或 ATP 水解通量 ($q_{ATP}$) 與生長速率 ($\mu$) 之間的線性關係：
$$q_{ATP} = \frac{\mu}{Y_{ATP}^{max}} + m_{ATP}$$
- $Y_{ATP}^{max}$：扣除維護消耗後的理論最大生長得率（每莫耳 ATP 生成的細胞生物質乾重，$g_{\text{DW}} / \text{mol ATP}$）。
- $m_{ATP}$：維持能量係數（Maintenance coefficient），即細胞在零生長狀態下，用於維持膜電位、修復 DNA/蛋白質受損結構、離子轉運及維持滲透壓所需的最低基礎 ATP 消耗速率（大腸桿菌約為 $1.0 - 3.5\text{ mmol ATP} / g_{\text{DW}} / \text{h}$）。

#### 3.3.2 單細胞層級的去偶聯 (Decoupling) 物理機制
在巨觀化學計量學中，$q_{ATP}$ 與 $\mu$ 被視為高度偶聯的線性函數。然而，Mother Machine 的單細胞數據揭示：**單個細胞內部的瞬時伸長速率 $\lambda(t) = \frac{1}{L}\frac{dL}{dt}$ 與瞬時 [ATP] 濃度經常出現顯著的去偶聯**。

```
              ┌────────────────────────────────────────────────────────┐
              │              單細胞能量去偶聯的三大主導機制            │
              └────────────────────────────────────────────────────────┘
                                           │
         ┌─────────────────────────────────┼────────────────────────────────┐
         ▼                                 ▼                                ▼
【核糖體翻譯的時間延遲】          【維持能量的不均勻消耗】          【持留菌與休眠重編程】
 • ATP 濃度提供能量底物            • 外排泵 (AcrAB-TolC) 偏倚分配   • 隨機波動使 ATP 跌破臨界閾值
 • 伸長生長主要取決於活性核糖體    • SOS 修復 (RecA 聚合) 耗能      • (p)ppGpp 活化，生長停滯 (λ=0)
 • ATP 快速恢復時，核糖體池重建需  • 造成相同 [ATP] 下，高耗能細    • 能量消耗轉入最低生存程序
   時數十分鐘，生長延遲滯後          胞生長顯著減緩                   • 與傳統 Pirt 模型徹底去偶聯
```

1. **蛋白質合成機械通量之時間延遲 (Time-lag Effect)**：
   - 細胞的體積伸長本質上是由胜肽鏈延伸通量所驅動。雖然 ATP 是胺基酸活化 (Aminoacyl-tRNA 合成) 與轉譯延伸 (EF-Tu 消耗 GTP，與 ATP 庫存平衡) 的底物，但轉譯速率受限於核糖體與 mRNA 的物理豐度。
   - 在飢餓細胞重新獲得營養時，細胞內 [ATP] 在數十秒至數分鐘內即飆升回 2.5 mM，然而核糖體的生合成與組裝需要數十分鐘。在此過渡期內，高 [ATP] 與低生長速率 $\lambda$ 同時存在，偶聯關係完全脫鉤。
2. **維持能量 ($m_{ATP}$) 的單細胞不對稱分配**：
   - **多藥外排泵偏倚分配** (Bergmiller et al. 2017)：大腸桿菌膜結合複合物 AcrAB-TolC 在分裂時呈現非均勻分配。繼承較多外排泵的子細胞，其質子泵與 ATP 消耗大幅偏向物質外排，導致用於生物合成的自由能受限，展現「高維持消耗、低生長速率」的表型。
   - **DNA 損傷修復**：活化 SOS 反應的單細胞，大量 ATP 被 RecA 核絲聚合、DNA 解旋酶與核酸修復複合物所佔用，此時細胞維持係數 $m_{ATP}$ 暴增數倍，生長完全停滯。
3. **細菌持留性 (Bacterial Persistence) 與低能量休眠態**：
   - Manuse et al. (2021) 與 Shan et al. (2017) 證實，持留菌並非傳統所認為由毒素-抗毒素 (TA) 模組特異性啟動，而是代謝酵素分子的隨機熱噪聲使某些單細胞的 [ATP] 跌破維持生命活動的臨界閾值。
   - 這一極端低能量狀態促發焦磷酸鳥苷 ((p)ppGpp) 介導的嚴格反應，核糖體形成二聚體失活 (100S 核糖體)，代謝通量降至極限基礎值。此時細胞雖然完全喪失生長能力 ($\lambda = 0$)，卻因抗生素作用靶標（青黴素結合蛋白 PBP、拓撲異構酶 GyrA）缺乏底物活性而免於被殺滅，展現出極致的表型抗藥性。

## 四、結論與未來研究展望

1. **感測器選擇指南**：
   - 對於以大腸桿菌為模型之**絕對 millimolar 級 ATP 濃度**監測，**QUEEN-2m** 憑藉其出色的抗 pH 波動性與精確的親和力 ($K_d \sim 4.5\text{ mM}$)，是當前最理想的工具。
   - 對於探討細菌熱力學自由能驅動力與腺苷酸能量荷研究，**PercevalHR** 能提供獨特的 [ATP]:[ADP] 比值資訊，但必須嚴格實施紅光 pHRed 雙通道校準以消除酸性干擾。
2. **微流體時序技術規範**：
   - 結合 **Mother Machine** 晶片已成為解析單細胞能量異質性的金標準。實驗設計必須在激發光強 ($<1.5\text{ W/cm}^2$)、短曝光 ($<50\text{ ms}$) 與適當時間間隔 ($5-10\text{ min}$) 之間建立最佳化折衷，嚴格排除光毒性對細胞代謝造成的人工抑制。
3. **前沿研究方向**：
   - **多色多模態代謝監測**：將 QUEEN-2m 與第二代單細胞感測器（如 NADH/NAD+ 感測器 SoNar、膜電位指示劑、核糖體報導螢光蛋白）進行多光譜共發色成像，建立單細胞多維能量地圖。
   - **AI 驅動之影像分析**：運用深度學習演算法（如 DeLTA 2.0、Omnipose）進行高通量、自動化的細胞分割、譜系追蹤與噪聲成分解耦。
   - **能量導向之臨床抗持久性策略**：利用單細胞 ATP 異質性機制，開發小分子代謝激活劑（如特定碳源輔助化合物），迫使處於低能量休眠的持留菌重啟 ATP 合成與轉譯活性，從而徹底消除臨床難治性慢性細菌感染。
